# 观象十阶段体验重构标准 v1

本文件是当前网站改造的冻结验收标准。实施必须按顺序推进；当前阶段未通过视觉、交互、移动端与无障碍验收前，不进入下一阶段。

## 总原则

- 保留宋画长卷、宣纸、墨色、朱砂、书法与留白的既有美术体系。
- 改变内容顺序、交互节奏和信息层级，不改变确定性排盘规则。
- AI 只负责澄清、整理和解释，不接触三个起卦数字，不参与确定性排盘。
- 用户提供的现实信息不能伪装成卦象证据。
- 不使用结果保证、宿命或夸张神秘语言。
- 音乐、动效、AI 对话、语音与分享均应可关闭或跳过。
- 桌面 hover 必须有键盘、触屏和滚动状态替代，并支持 `prefers-reduced-motion`。
- 测试、编译和静态截图不能替代完整用户流程验收。

## 十阶段顺序

1. 入境：纯粹首页氛围、山水、文字、声音。
2. 明法：解释观象是什么、需要约三分钟，并由用户确认准备状态。
3. 正问：写下一件具体而真实的事，并提供四个精选例句。
4. 辨识：AI 一次问一个问题，整理事实、未知、行动、回应与真实需求。
5. 定问：用户接受、修改或保留最终题目。
6. 成卦：三个呼吸、复述问题、依次取三数、三数汇聚成卦。
7. 见卦：先只看卦象、卦名、卦序和卦辞。
8. 读卦：本卦 → 互卦 → 变卦 → 动爻 → 体用旺衰，并分别结合现实解释。
9. 收束：最后才给可借之力、当慎之处、下一步和转向条件。
10. 留存：主动存入观事簿或导出同风格离线 HTML，并提供隐私分享方案。

- [x] 首屏只保留品牌、题签、经典引文、山水、声音控制和极轻的向下提示。
- [x] 首屏不出现功能说明、产品承诺或无意义跳转按钮。
- [x] 首屏导航不破坏入境；进入页面时隐藏，下滑后再显现。
- [x] “观象”是明确的第一视觉主体，经典引文不压过品牌。
- [x] 题字动效具备静止、滚动进入、桌面 hover/focus、触屏轻触四种状态。
- [x] 首次进入先显示宣纸底色，再由墨滴落下、墨晕扩散逐层显影完整首屏；定格画面不是预先摆放的静态特效。
- [x] 完整入场时长不少于五秒；当前节奏约 7.6 秒，墨滴先缓慢下落，接触后再逐层晕染与显影。

- [x] 太极只在题字背后以低透明度呼吸显隐，不作为固定背景图常驻。
- [x] 船、飞鸟与瀑布分别具备独立长周期漂移、飞行与错相位下落动画。
- [x] 船与鸟具备克制的长周期微动，不使用夸张位移或运动轨迹。
- [x] 减少动态效果时改为稳定静态墨迹，不播放持续动画。
- [x] 增加默认静音的“闻琴／静音”控制；音乐不是进入网站的条件。
- [x] 宽屏、窄桌面／平板和手机采用三套专用构图；按纵横比自动切换，关键题字、船、鸟、引文与入口均保留安全边距。
- [x] 首屏默认锁定滚动，只有点击“了解观象之法”的箭头热区才解锁并进入第二屏。
