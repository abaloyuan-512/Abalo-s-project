# 观象智能能力诊断集 v1.0

## 目的

本目录只服务于《观象智能能力优化终版方案》阶段 0：建立可复核的现状基线，判断现有材料是否足以验证两个问题：

1. 当前辨识是否经常停留在信息总结，而没有帮助用户找到真正的决策瓶颈；
2. 当前解卦是否存在“引用了卦象，但判断并非因该卦而成立”的问题。

阶段 0 不实施任何优化。这里的案例、标签和参考判断包都不是生产知识库，也不进入模型上下文。

## 当前状态

`PASS_WITH_OPEN_ITEMS`

2026-08-06 已回收并冻结产品负责人内部盲评，完成揭盲、质性证据整理、评分锚点纠偏和产品边界客观复核。两个核心问题已获得足以支持内部最小实验的证据结论；独立目标用户、独立易学专家、知识审核状态和敏感数据留存仍为开放项。当前结论见 `stage0_acceptance_report_v2.md`。

当前仓库中仍没有可核实的真实用户完整案例。首批材料只能由以下三类证据组成：

- 合成确定性基线；
- 合成输入上的历史真实模型输出；
- 有产品负责人反馈的产品校准样本。

所有材料必须保留来源类型，不能冒充真实用户案例、易学专家结论或唯一标准答案。

为补齐现状基线，阶段 0 另用完全冻结的当前辨识版本运行了 4 个明确标注为合成的逐轮案例。它们只证明当前产品行为，不是用户反馈，也不是阶段 1 优化方案。

## 阶段 0 范围锁

允许：

- 只读盘点和引用既有材料；
- 复制经过脱敏的合成输出；
- 建立案例索引、参考判断包和盲评材料；
- 记录执行、决策、风险和偏差；
- 在确有必要时，以完全冻结的现有版本补齐基线。

禁止：

- 修改产品代码、Prompt、模型或参数；
- 修改确定性排盘算法或版本化术数规则；
- 修改 UI、接口、数据库或旧入口；
- 建设生产案例库或检索系统；
- 启用当前被关闭的详细解卦；
- 自动进入阶段 1、2 或 3；
- 让 Codex 冒充真实用户或易学专家完成验收。

## 案例构成

- 4 个明显失败案例：Gate 0 同盘同结构化输入、只换自由问题，但报告逐字段相同；
- 4 个中间候选：合成输入上的历史真实模型输出，技术验证通过但尚无人类价值盲评；
- 2 个优秀保护案例：产品负责人明确给出 85 分以上或通过评价的产品校准样本。

“中等”和“优秀”只描述已有证据状态，不表示易学正确性已经通过。

## 状态定义

- `PACKET_READY_FOR_REVIEW`：案例、来源、盲评表和治理记录已经齐全，可以交给指定评审；
- `STAGE0_DIAGNOSIS_COMPLETE`：真实指定用户/目标用户和易学评审完成评价，两个核心问题获得证据结论；
- `PASS_WITH_OPEN_ITEMS`：材料可用，但真实用户、易学评审或完整辨识对话仍有缺口；
- `FAIL`：违反阶段边界、案例比例不符、来源不可追溯、敏感信息未处理，或把待评假设写成已验证结论。

未经用户确认，不得从本目录的任何状态自动进入下一阶段。

## 评审隔离

评审者只能读取 `review/reviewer_cases/` 中与其角色对应的数据和同角色表单。`cases.json`、`case_index.json`、`review/reveal_key.json`、历史反馈和治理日志只供主代理与 PMO 使用；全部评审结果冻结前不得揭盲。
