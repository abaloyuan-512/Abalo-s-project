# 观象 v16 个性化解读 Gate 0 审计报告

## 结论

当前观象具备明显的“解释文字差异”，但不具备“卦象驱动的行动差异”。

在现实问题、领域、目标、时间范围、阶段和关键不确定项完全不变时，本次审计穷举了64个本卦与6个动爻，共384个不同盘面。结果如下：

| 报告字段 | 不同输出数 |
|---|---:|
| `what_it_means` | 384 |
| `answer` | 155 |
| `evidence_path` | 90 |
| `priority` | 4 |
| `next_action` | 1 |
| `continue_signals` | 1 |
| `pause_signals` | 1 |
| `boundary_note` | 1 |

384个盘面得到的行动全部是：

> 你已经在推进，请对方确认一个可验收节点；只在实际回复和行动出现后，再决定是否追加投入。在这段观察范围内，只用阶段反馈更新判断。

因此，Gate 0确认的不是“观象全站永远只有一个行动模板”，而是更精确的事实：

> 在用户现实选项不变时，改变本卦、变卦、动爻、体用、旺衰和程序结论，均不会改变当前的下一行动、继续信号或暂停信号。

## 审计方法

### 复验坐标

- 产品行为基线：`7e96712c1ffc2c3209063c0efd60c33f8f1916ef`（v16行为对照）。
- 治理工作基线：`e75594208643232ae35134a70b41be1aeea74229`（启动Gate 0时的分支HEAD）。
- 固定服务端时间：见`fixed_cases.json`与`baseline_manifest.json`。
- Python版本、时区、生成器版本及全部机器可读文件哈希：见`baseline_manifest.json`。
- 384个完整确定性结果的汇总SHA-256：见`audit_summary.json`的`complete_sweep_sha256`。
- 4组自由问题的完整输入、请求哈希与逐字段报告输出：见`question_text_pair_outputs.json`。
- 锁定测试集尚未创建或暴露；术数审核者尚未指定。

### 1. 盘面敏感性

固定以下现实输入：

```text
问题：这次合作，我还应该继续投入吗？
领域：项目与合作
目标：规划下一步
范围：未来30天
阶段：已经在推进
不确定项：对方回应
```

随后穷举：

```text
上卦数：1—8
下卦数：1—8
动爻数：1—6
```

共得到384个互不相同的“本卦＋变卦＋动爻”签名，覆盖64个本卦与64个变卦。

### 2. 自由问题敏感性

设置4组对照，每组保持数字和全部结构化选项不变，只更换用户的具体问题。例如：

```text
我是否应该继续争取这次晋升？
我是否应该接受新的岗位安排？
```

4组对照中，请求哈希全部改变，但`clarity_report`全部逐字段一致，连报告哈希也完全相同。

### 3. 结构化选项敏感性

固定同一个盘面，穷举当前所有合法结构化组合：

```text
17个合法领域—目标组合
× 4个时间范围
× 4个阶段
× 4个关键不确定项
= 1088个合法现实上下文
```

1088个组合共形成256种`next_action`、4套继续信号和4套暂停信号。决策目标不改变`next_action`。

这说明当前行动差异来自有限表单选项，而不是卦象，也不是用户自由问题。

## 直接技术原因

| 机制 | 当前行为 | 证据 |
|---|---|---|
| 卦象重点 | 本卦和变卦进入`answer`、`what_it_means` | `src/abalo_iching/application/sites_clarity_report_v3.py`中的`_HEXAGRAM_FOCUS`与`build_clarity_report` |
| 下一行动 | 只拼接阶段、领域×不确定项、时间范围 | 同文件`_STAGE_PREFIX`、`_NEXT_ACTIONS`、`_HORIZON_SUFFIX`及`next_action`装配 |
| 继续/暂停信号 | 只按领域选择 | 同文件`_CONTINUE_SIGNALS`、`_PAUSE_SIGNALS` |
| 用户自由问题 | 规范化、显示、哈希；不进入报告语义 | `src/abalo_iching/application/sites_meihua_service_v3.py`与`sites_question_context_v1.py` |
| 当前测试 | 证明64卦的`answer`不同，但没有要求64卦改变行动 | `tests/test_sites_meihua_v3.py::test_each_base_hexagram_receives_a_distinct_plain_language_emphasis` |
| 体验规范 | 明确要求“一个最小、可逆的下一步” | `docs/specs/MEIHUA_SITES_EXPERIENCE_SPEC_V3.md` |

## 量化观察

在固定的384盘面样本中：

- “观察”出现在384份报告中；
- “反馈”出现在384份报告中；
- “投入”出现在384份报告中；
- “边界”出现在290份报告中；
- “调整空间”出现在144份报告中；
- “可逆”出现在48份报告中。

这些统计不能单独证明词语本身有问题，但与行动完全不随卦象变化结合后，能够解释用户连续体验时为何会感到：卦名和解释换了，背后的思想仍然是观察、反馈、控制投入和保留空间。

## 产品承诺差距

当前页面告诉用户：

> 你写下的问题和现实处境，帮助我们从卦象中找到与眼前这件事有关的重点，并整理出可以采取的应对方法。

当前报告边界说明也写道：

> 你写下的问题帮助我们把卦意说到具体事情上。

但当前程序没有解析自由问题的含义。自由问题变化只会改变页面回显与请求哈希，不会改变报告正文。

Gate 0不修改这段页面文字，因为视觉与正式网站仍在冻结范围内。但后续必须二选一：

1. 新解释路径真正理解自由问题，并清楚声明它只参与解释、不参与排盘；或
2. 如果个性化实验失败，修改页面承诺，避免继续暗示自由问题已被理解。

## Gate 0验收建议

本证据包足以冻结下面这一问题定义：

> 当前同质化的核心不是缺少64卦文案，而是卦象差异和用户自由问题均没有进入行动决策层；当前行动差异仅来自有限的结构化表单矩阵。

如果产品负责人认可该问题定义，下一阶段才进入Gate 1：通过产品负责人A/B/C选择冻结“什么是有价值、有判断但不过界的观象答案”，并设计不会提前暴露给执行者的锁定测试集。

Gate 0本身不授权模型调用、Prompt修改、实验代码开发或网站集成。
