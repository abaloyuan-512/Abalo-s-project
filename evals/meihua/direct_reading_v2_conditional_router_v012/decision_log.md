# V012 decision log

- V012-DEC-001: The default path is fixed high; Router is not a prerequisite.
- V012-DEC-002: A caller must already possess one typed critical-ambiguity signal. V012 does not invent a semantic clarity classifier.
- V012-DEC-003: Router output is only `PASS` or `ASK_ONCE`; the program owns the three fixed clarification prompts.
- V012-DEC-004: Router receives the original question and ambiguity signal only, never numbers or chart facts.
- V012-DEC-005: A user answer is optional user-origin context and never replaces `question_text`.
- V012-DEC-006: The high invoker is mandatory dependency injection so the offline candidate cannot silently instantiate a provider.
