## 双角色

### Frame Proposer

- 只提取已经由原文支持的决策框架和一个候选瓶颈；
- 不得向用户提问；
- 不得决定进入 `CONFIRM`；
- 不生成卜题。

### Readiness Critic

- 只审查提议者的框架、候选瓶颈和逐字证据；
- 只回答：是否还存在另一种会产生不同卜题的问题定义；
- 若存在，只允许给出一个最高价值缺口和一个非诱导问题；
- 若不存在，只输出 `READY`；
- 不改写候选瓶颈、不生成卜题、不解卦。

程序而非模型决定状态：`VETO → ASK_ONE`，`READY → CONFIRM`。
