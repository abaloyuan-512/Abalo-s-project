# Direct Reading V2 非生产实施阶段

阶段编号：`DIRECT_READING_V2_NONPROD_IMPLEMENTATION_V001`

本阶段只实现隔离的 Python 应用服务和测试入口。有效输入只有用户原始问题与三个起卦数；辨识、定问、`confirmed_facts`、`unknowns` 均不是生成资格门槛。

## 范围锁

- 复用现有确定性排盘，AI 不参与排盘。
- 复用研究验证通过的自然文本 Prompt、模型与生成参数。
- 新增 Direct Reading 专用完整性与内容释放门。
- 完成一次真实非生产 Canary、专项测试、全量 pytest 和反向测试。
- 不接入正式网站，不修改现有默认旅程，不删除旧入口。
- 不修改规则、经典数据、旧 Owner Preview 或 Page 8 合同。
- 不在本阶段加入流式传输、案例库、Critic、自动修复调用或模型降级。

## 完成定义

不是“代码写完”，而是验证：仅凭问题和确定性卦盘，隔离服务能否稳定返回完整、紧扣所问且通过硬边界的解卦；所有失败是否能显式关闭而不冒充成品。
