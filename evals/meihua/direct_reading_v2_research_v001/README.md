# 观象直接解卦研究 v0.1

## 已授权目标

验证用户只提供“所问之事＋三个数字”时，观象能否依靠确定性排盘与OpenAI生成一篇达到或超过ChatGPT参考答案的完整解卦。

## 产品原则

- 辨识与定问不是成卦、解卦的必备条件。
- 没有辨识信息时仍必须生成与原问题相关的完整解卦。
- 有辨识信息时只能增强具体程度，不能控制是否允许解卦。
- 是否最终保留辨识与定问，必须等本研究完成后再决定。

## 本阶段范围

- 使用公开合成历史取数案例和用户本次主动提供的换工作案例；
- 程序核对本卦、互卦、动爻、变卦和经典文本；
- `chat-latest`作为ChatGPT Instant参考组；
- `gpt-5.6-sol`作为观象极简直接解卦候选组；
- 比较问题相关性、卦理链条、判断、行动边界、反向提醒、转向条件、事实准确性、Token和延迟。

## 禁止事项

- 不修改正式网站、UI、生产API、数据库或确定性排盘规则；
- 不删除辨识、定问或旧解卦入口；
- 不继续阶段1E正式实验；
- 不建设案例库、不训练模型、不增加Critic/Proposer；
- 不把ChatGPT生成内容直接当成易学标准答案。

## 决策闸门

研究完成后只提交结论和建议；辨识/定问去留、正式V2实施及旧链路迁移均需用户另行确认。
