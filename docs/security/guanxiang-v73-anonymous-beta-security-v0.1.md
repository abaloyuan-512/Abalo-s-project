## 1. 范围与安全目标

本文件只覆盖 V73 Product Beta 1 新增的匿名体验凭证、Direct Reading V2、intake、
预算/限流/幂等控制、证据和停止开关。确定性排盘、V72 内容、Prompt、旧版入口和
引擎规则不在改动范围内。

必须同时成立：

- 未授权者不能创建、读取或恢复他人的体验；
- 同一逻辑请求至多触发一次对应模型调用；
- 预算、凭证、限流或控制库状态不确定时不调用上游；
- 高风险问题不进入排盘和 high；
- 原始凭证、真实问题、模型原文、出生资料和密钥不进入日志、响应或 Git；
- 任一自动或人工停止在冻结边界内可验证地生效。

### 5.1 固定限流边界

体验凭证由受控邀请流程预先签发，不提供公共自助签发接口。所有计数键仅保存主体
摘要，窗口使用服务端时间；限流存储不可用时 fail closed。

| ID | 主体 / 窗口 / 上限 | 第 N+1 次期望 |
|---|---|---|
| RL-01 | 单凭证生命周期：intake POST 1 次 | 同ID同载荷：进行中202/完成200；异载荷409；0新预留/0新调用 |
| RL-02 | 单凭证生命周期：high POST 1 次 | 同ID同载荷：进行中202/完成200；异载荷409；0新预留/0新调用 |
| RL-03 | 单 IP 60分钟：无效凭证尝试 6 次 | 第7次 HTTP 429；0预留/0调用；窗口后恢复 |
| RL-04 | 单 IP 10分钟：新体验生成 POST 6 次 | 第7次 HTTP 429；0预留/0调用；GET 不占此额 |
| RL-05 | 单凭证 5分钟：GET 轮询 180 次 | 第181次 HTTP 429；0预留/0调用；覆盖现有1.5秒×140次恢复 |
| RL-06 | 全局同时执行：intake 2、high 1 | 超出者 HTTP 429+Retry-After；0新增预留/调用 |

RL-04 只限制会产生新模型调用的 POST；同一合法请求的幂等恢复不增加 Provider 次数，
但仍受合理的传输层防滥用限制。Gate 1 实现若需改变任一数值，必须先升级本文件并
由 QA、反向论证与 PO 重签，不能仅改环境变量。

固定旁路组还必须包含：每类高风险至少一个隐晦/拆分/混合表达、至少一个语义邻近

### 5.2 统一 HTTP 合同

POST、GET 与 intake 使用同一不可枚举合同；公开响应不得透露凭证或任务是否曾存在。

| HTTP | 公共错误码/状态 | 唯一适用情形 | 前端行为 |
|---:|---|---|---|
| 200 | `COMPLETED` | 合法已完成结果或同ID同载荷完成态 | 展示白名单产品投影 |
| 200 | `SAFETY_EXITED` | 任一自由文本入口命中安全退路 | 展示现实求助边界；不重试 |
| 202 | `IN_PROGRESS` | 合法新任务或同ID同载荷进行态 | 仅按冻结间隔GET |
| 400 | `INVALID_REQUEST` | schema/长度/字符等公开请求格式错误 | 修正本地输入；不自动重试 |
| 404 | `EXPERIENCE_UNAVAILABLE` | 无效、过期、撤销、耗尽凭证；IDOR；任务未知 | 统一结束体验，不区分原因 |
| 409 | `IDEMPOTENCY_CONFLICT` | 同request ID不同规范化载荷 | 不重试，不创建新ID绕过 |
| 429 | `CAPACITY_UNAVAILABLE` | 频率、次数、预算或并发耗尽 | 尊重`Retry-After`；不自动POST |
| 503 | `BETA_UNAVAILABLE` | 停止位、缺配置、控制库或依赖不可用 | 停止生成；按停止GET策略处理 |

任何实现若改变 HTTP 或公共错误码，必须先升级本文件与前端恢复测试。
