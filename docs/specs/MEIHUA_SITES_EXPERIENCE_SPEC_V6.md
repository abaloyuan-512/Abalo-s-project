# 观象 Sites 体验规范 V6

状态：P1–P9 正式冻结基线（产品负责人验收通过）
确认日期：2026-08-17
替代范围：继承 V5 的动态 P9 与发布门；补充 P1–P9 的历史裁决优先级和逐页恢复边界。确定性排盘规则、条件辨识契约和 Direct Reading high 契约均未改变。

## 1. 历史裁决优先级

1. 产品负责人较晚、明确提出的覆盖性决定，高于较早的冻结描述。
2. 较晚决定只覆盖其明确点名的内容；没有被点名的布局、视觉、交互和文案继续使用原定稿。
3. 系统升级引起的必要说明文字调整，不等于整页解冻，也不得借此重写视觉或其他文案。
4. 历史快照、旧部署和中间实验不能覆盖上述裁决；不得因为某个版本“测试通过”就把中间稿当成产品定稿。

## 2. 唯一用户动线

- 原题无歧义：P1 → P2 → P3 → P6 → P7 → P8 → P9。
- 原题命中既有辨识器：P1 → P2 → P3 → P4 一次澄清 → P5 确认 → P6 → P7 → P8 → P9。
- 客户不得主动选择“直接成卦”或“进入辨识”；P3 提交后由系统自动判断。
- P4/P5 不是必经页。不得恢复八朵花、多轮固定问答或旧 Guided Intake 主流程。
- 条件辨识继续使用 `SITES_CONDITIONAL_INTAKE_PRODUCT_V1`；本规范不修改其模型、提示词、判断次数、澄清次数或失败策略。

## 3. P1–P9 恢复边界

### P1 首页

- 使用逐页验收后的首页定稿；布局、水墨背景、题字、古琴、飞鸟、舟形入口与开场动效均不得重做。

### P2 观象之法与准备

- 视觉、山河背景、白浪呼吸、书法交互和排版继续使用第二页定稿。
- 后期覆盖项必须保留：删除“让我用四个步骤”；显示“让我带你进入观象”。
- 继续显示“进入第一步：正问”和“进入正问”。这只是体验编号，不得暗示 P4/P5 必经。

### P3 正问

- 保留正问定稿的山、松、云海、云瀑、输入区和单一继续入口。
- 提交后由系统自动判断是否需要辨识；不得出现两个并列选择按钮。
- 条件说明可以解释“只在必要时辨清一处歧义”，但不得借系统升级重写其余已定稿视觉。

### P4 辨识

- 只在 `ASK_ONCE` 时进入；沿用定稿的背景、人物、菊花、仙鹤和版式。
- 客户只回答既有系统给出的一个澄清问题；不得恢复八朵花进度、多轮问答或发带动效。

### P5 定问

- 保留定问定稿的落霞、白鹭、芦苇、太极八卦入口和一屏布局。
- 必须显示实际采用的最终问题；发生澄清时，同时显示本次辨识确认，不能让客户误以为回答丢失。
- 清晰问题不进入 P5。

### P6 成卦

- 保留成卦定稿的牡丹、花瓣、三数输入、排版和一屏交互。
- 后期覆盖项必须保留：删除“心中默念最终确认的问题”，避免与 P5 重复。
- 三个数字只交给确定性程序排盘；AI 不参与排盘。

### P7 卦象

- 保留卦象定稿的太极、锦鲤、水墨六爻、卦名、卦序和详细解卦入口。
- 不显示用户所问问题，不增加摘要、侧栏或新的信息块。

### P8 读卦五幕

- 保留已冻结的本卦、互卦、动爻、变卦、体用与旺衰五幕及其视觉交互。
- 保留 2026-08-16 最终验收增量：移除来源/免责声明串；本卦、互卦、变卦显示上下卦；动爻先原文后白话并支持卦象放大提示；体用旺衰中文化；第五幕完整一屏；右下角使用太极八卦“进入观象寄语”；进入 P9 后不得回滚 P8。

### P9 观象寄语

- 保留已定稿的背景、北斗星光、排版、继续追问、分享解卦和观事簿提示。
- 同一次 fixed-high 调用必须生成 `GUANXIANG_P9_FINALE_V1` 两句动态答案；不得增加 P9 模型调用。
- “一卦一语/经典余韵”已在后续决定中取消，不得恢复。
- 不得展示旧五板块，不得使用搬家样例或临时文案回退。

## 4. 防回退验收

1. P2 不出现“让我用四个步骤”。
2. P3 只有一个继续入口，不出现“直接进入成卦/先理一理再进入辨识”的客户选择。
3. clear 路径 P3 → P6；`ASK_ONCE` 路径 P3 → P4 → P5 → P6。
4. P4 不出现八朵花进度或多轮问答。
5. P5 显示最终问题和已发生的辨识确认。
6. P6 不重复“心中默念最终确认的问题”。
7. P7 不显示所问问题。
8. P8/P9 使用冻结视觉和后期明确增量；P9 独占一屏，不能回滚 P8。
9. P9 不出现经典余韵、旧五板块或离线搬家样例。
10. Python 全量 `pytest`、站点测试、构建和静态检查通过后，才允许发布。
