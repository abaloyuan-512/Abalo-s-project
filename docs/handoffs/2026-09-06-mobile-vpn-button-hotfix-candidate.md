# 观象 VPN 手机端按钮修复候选版（2026-09-06）

## 基线与边界

- 产品与视觉基线：`guanxiang-mobile-production-frozen-20260904`（Sites 第 6 版）。
- 实际发布候选保留此后已上线的公开访问边界与两次 API 防护修复，建立在当前 Sites 源码 `a46182c69ba76ee21126c044b17da245fcfc4057` 上，不回退这些安全修复。
- 目标：只修复手机输入法弹出时，取数页“开始成卦”按钮随可视窗口上移并遮挡取数框的问题。
- 不修改网页版、确定性排盘、解卦算法、提示词、API 契约、P1–P9 页面顺序或其他冻结视觉内容。
- 原冻结版继续保留，可随时回退；本候选版必须经产品负责人真机验收后才能冻结为 VPN 手机端 v1.0.1。

## 根因与修复

- 根因：页面全局高度跟随 `visualViewport.height`；手机输入法打开后可视高度缩小，底部定位的按钮因此上移。
- 修复：取数页单独保存键盘打开前的稳定画布高度。输入法只遮盖画布，不再重新排列画布；按钮保持原来的页面坐标。键盘关闭、普通窗口高度变化或横竖屏切换时仍会重新计算。
- 短屏设备保留至少 660px 的取数画布，并允许页面滚动到完整按钮，避免按钮与第三个数字相撞。

- Sites 构建成功。
- 原有手机端 48 项测试全部通过；新增 2 项键盘画布测试通过；其他渲染与流程测试 13 项通过。

- 320×568 短屏：按钮与第三个输入框仍有 53.8px 间隔，660px 画布可滚动到完整按钮。
